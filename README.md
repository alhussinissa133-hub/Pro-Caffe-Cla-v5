# Pro Caffe — محاسبة بيع وشراء وديون

## التشغيل
1. افتح المجلد في Android Studio (Koala أو أحدث) واترك Gradle يعمل Sync (يحتاج إنترنت أول مرة).
2. Build > Build APK(s) ثم ثبّت الملف على الموبايل.

## ملاحظات
- أسعار الأصناف الأولية = 0: ادخل لتبويب "مخزون" وعدّل سعر كل صنف وعملته (ليرة/دولار) وكمية المخزون.
- سعر الدولار: يُجلب من sp-today.com، وإن فشل الجلب يمكن إدخاله يدوياً من الإعدادات.
- المبالغ في التقارير والديون محفوظة بالليرة حسب سعر الدولار وقت العملية.
- النسخ الاحتياطي: من الإعدادات (ملف JSON).
